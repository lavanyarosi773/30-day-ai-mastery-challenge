WEEK 1 AI Basics — Days 1–7
01
What is Artificial Intelligence?
The foundation of everything
CONCEPT ▼
Concept
AI (Artificial Intelligence) is the science of making computers think, learn, and make decisions like humans. It has 3 main branches: Machine Learning (learns from data), Deep Learning (brain-like neural layers), and Generative AI (creates content — text, images, code).
Real Life Examples
Google Translate, Siri, Alexa, Netflix recommendations, Face ID — all powered by AI! Your smartphone alone has 10+ AI features built in.
Exercises
→ List 5 AI features on your phone (camera, voice assistant, suggestions, etc.)
→ Write down the key differences between AI and traditional software
→ Ask ChatGPT or Claude: "Explain AI to a complete beginner in simple terms"
→ Watch one "AI for beginners" video on YouTube (30 min)
02
Machine Learning — How Do Machines Learn?
Data → Pattern → Prediction
CONCEPT ▼
Concept
Machine Learning means a computer learns patterns from data — without you writing explicit rules. There are 3 types: Supervised Learning (labeled data), Unsupervised Learning (unlabeled data), and Reinforcement Learning (reward-based system).
Real Example
A spam filter learns by studying thousands of spam emails. Netflix learns your taste by watching your watch history. Both are ML in action.
Exercises
→ Go to teachablemachine.withgoogle.com and build a free image classifier
→ Draw a diagram explaining Supervised vs Unsupervised learning
→ Find 3 real-world ML use cases in your daily life

Just 4 things to learn today: Variables (store data), Lists (store collections), Loops (repeat actions), Functions (reusable code blocks).

04
Neural Networks — How AI Mimics the Human Brain
Neurons, Layers, Activation Functions
CONCEPT ▼
Concept
The human brain has billions of neurons that pass signals to each other. A neural network mimics this structure: Input Layer → Hidden Layers → Output Layer. Deep Learning simply means using many hidden layers. More layers = ability to learn more complex patterns.
Visualize It
Visit playground.tensorflow.org — an interactive tool where you can visually build and train a neural network right in your browser. Try adding and removing neurons to see how accuracy changes.
Exercises
→ Spend 10 minutes exploring playground.tensorflow.org
→ Test: does adding more hidden layers improve accuracy?
→ Draw a neural network diagram in your notebook (Input → Hidden → Output)
05
Data — The Fuel of AI
Datasets, Kaggle, and Data Types
CONCEPT ▼
Concept
Without data, there is no AI — "Garbage in, Garbage out." Data comes in two types: Structured (tables, CSV files, spreadsheets) and Unstructured (images, audio, raw text). In real projects, data cleaning and preparation takes up to 70% of total work time.
Free Dataset Source
Kaggle.com is the world's largest data science community. It offers free datasets, code notebooks, and competitions for all skill levels.
Exercises
→ Create a free account on kaggle.com
→ Download the famous "Titanic" dataset and open it in Excel or Google Sheets
→ Analyze which columns might affect passenger survival
→ Identify where missing values exist in the dataset

Prompt Engineering — The #1 Skill of the AI Era
How to talk to AI and get great results
EXERCISE ▼
Concept
A prompt is the instruction you give to an AI. The quality of your prompt directly determines the quality of the output. Use this formula for great prompts: Role + Context + Task + Format + Constraints.
Example
Weak: "Write a poem." | Strong: "You are a professional poet. Write a 4-line rhyming poem about the monsoon season, suitable for a 10-year-old child, using simple and vivid language."
Exercises
→ Take the same topic, write a weak prompt and a strong prompt, then compare the results
→ Write a perfect "AI tutor" prompt for your favorite subject
→ Try 5 different prompt styles on Claude or ChatGPT and note the differences
→ Create a custom persona prompt and have a conversation with it

13
Large Language Models — How Does ChatGPT Work?
Transformers, Parameters, Training
CONCEPT ▼
Concept
LLMs (Large Language Models) are trained on trillions of words and hundreds of billions of parameters. They use the Transformer architecture (introduced in 2017). GPT-4, Claude, Gemini, and Llama are all LLMs competing at the frontier.
Key Terms to Know
Token = a chunk of text (word or sub-word). Context Window = how much the model can "remember" at once. Temperature = controls creativity (0 = precise, 1 = creative).
Exercises
→ Ask the same question to ChatGPT, Claude, and Gemini — compare their answers
→ Test hallucination: ask about a very recent event and fact-check the response
→ List 5 key limitations of LLMs (bias, knowledge cutoff, hallucination, etc.)

TensorFlow & PyTorch — Deep Learning Frameworks
The industry-standard tools
CONCEPT ▼
Concept
TensorFlow (by Google) — production-ready, uses the beginner-friendly Keras API. PyTorch (by Meta) — popular in research, more Pythonic and flexible. Both are widely used in industry. Beginners are recommended to start with TensorFlow + Keras.

16
CNNs — How Does AI "See" Images?
Convolutional Neural Networks
CONCEPT ▼
Concept
CNNs (Convolutional Neural Networks) are specialized for processing images. The pipeline: Convolution layer (detects features like edges) → Pooling layer (reduces size) → Flatten → Dense (classifies). Used in face recognition, medical imaging, and self-driving cars.
Exercises
→ Load the MNIST dataset: from tensorflow.keras.datasets import mnist
→ Build a model with Conv2D + MaxPooling + Flatten + Dense layers
→ Train for 5 epochs and aim for 95%+ accuracy
→ Test the model on a photo of your own handwritten digit
17
NLP — How Does AI Read and Understand Text?
Natural Language Processing basics
CONCEPT ▼
Concept
NLP (Natural Language Processing) enables AI to read, understand, and generate human language. The standard pipeline: Text → Tokenize → Clean → Vectorize → Model. Core tasks include: Sentiment Analysis, Translation, Summarization, Q&A, and Named Entity Recognition.
Exercises
→ Install NLTK and tokenize a movie review or news article
→ Remove stop words and count word frequencies
→ Generate a WordCloud to visualize the most common words
18
Transformers & Attention — The Secret Behind GPT
The architecture that changed everything
CONCEPT ▼
Concept
"Attention Is All You Need" — the 2017 Google paper that revolutionized AI. Self-attention allows the model to understand relationships between words in a sentence. Example: In "The cat sat on the mat because it was tired," attention helps the model understand that "it" refers to "the cat." GPT, BERT, and all modern LLMs are Transformer-based.
Exercises
→ Install the library: pip install transformers
→ Create a sentiment-analysis pipeline and test several sentences
→ Try a text-generation pipeline — give it a story opening and let it continue
19
RAG — Make AI Read Your Own Documents!
⚡ Difficult — High value concept!
DIFFICULT ▼
Concept
RAG (Retrieval-Augmented Generation) lets you feed your own documents (PDFs, notes, docs) to an LLM so it can answer questions about them. Pipeline: Documents → Chunks → Embeddings → Vector Database → LLM. Businesses use this to build AI on top of their private knowledge bases.
Exercises
→ Go to ChatPDF.com, upload any PDF, and ask it questions
→ Follow the LlamaIndex quickstart tutorial at docs.llamaindex.ai
→ Try uploading a textbook chapter and ask it to generate exam questions
20
AI Ethics & Responsible AI
Bias, Hallucination, Privacy & Safety
CONCEPT ▼
Concept
Hallucination: AI sometimes confidently states incorrect information. Bias: If training data is biased, the model will be too. Privacy: Never share sensitive personal data with AI systems. Responsible AI means understanding these risks and using AI thoughtfully and ethically.
Exercises
→ Try to get ChatGPT to hallucinate — ask about a very obscure or fictional fact
→ Research one real-world AI bias case study (e.g., hiring algorithms, facial recognition)
→ Write your own 5 rules for using AI responsibly

Vector Databases — Giving AI a Long-Term Memory
ChromaDB & semantic search
DIFFICULT ▼
Concept
A vector database converts text into numerical vectors (embeddings) and stores them for fast similarity search. Semantic search finds results by meaning, not just keyword matching — search for "courage" and get "bravery" as a result. Vector DBs are essential for RAG systems.
Exercises
→ Install ChromaDB: pip install chromadb (free, runs locally)
→ Add 20 quotes or proverbs to your vector database
→ Run a semantic search query and observe how meaning-based results differ from keyword results
